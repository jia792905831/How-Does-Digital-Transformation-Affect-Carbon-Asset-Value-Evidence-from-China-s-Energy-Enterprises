# How Does Digital Transformation Affect Carbon Asset Value: Evidence from China's Energy Enterprises
This repository contains the Stata dataset and replication code for the empirical analysis in the corresponding paper.

## File list
- `finial_data_.dta`: Cleaned firm-level panel dataset
- `finial_Code_.do`: Main Stata replication script
